# Your own photos

Drop image files here and point a program at one with the `image` field:

```json
{ "name": "10K in 10 weeks", "image": "/static/img/my-photo.jpg" }
```

The photo replaces the drawn cover on both the card and the program page.
Landscape crops best (roughly 3:1). Without `image`, the program uses its
generated artwork, picked with `art`: `route`, `track` or `weights`.

Only use pictures you have the right to use — your own, or ones you have a
licence for.
